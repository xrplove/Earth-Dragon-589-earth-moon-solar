# Lunar imagery


`/textures/moon/color.jpg`: NASA CGI Moon Kit 2019 8K color map, derived from LROC WAC imagery. JPEG quality 93. `/textures/moon/height.png`: LOLA 16-pixels-per-degree unsigned TIFF, converted from half meters relative to 1,727.4 km to elevation in km relative to 1,737.4 km, then encoded to 8-bit across −12 to +12 km. Color and elevation are both centered on longitude 0°. Three.js UVs align that meridian with geographic +X. Vertex displacement preserves physical scale; bump shading supplies finer relief. Quantization is about 94 m. Original source elevation range: −8.9815 to +10.6855 km.
